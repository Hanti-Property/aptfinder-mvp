단지 동별 좌표 자동 추출기 · V-World 건물 공간정보

단지명으로 필터하고, 지도에서 단지 영역을 지정하면 동별 건물 좌표를 자동 추출합니다. (수동 클릭 불필요)

준비됨. ① 단지명 입력 → ② 주소검색 또는 지도 이동으로 단지가 화면에 꽉 차게 → ③ [추출] 클릭.

🔍 지도 클릭 → 단지 자동조회

지도에서 재건축 단지를 터치하세요.
클릭 지점 주소 → 건축물대장·토지대장·실거래를 자동 조회해 여기 표시합니다. (검수용)

사용법 (동별 좌표 추출)

1. 상단에 단지명 입력 (건물명 앞부분과 매칭됨)
2. 주소검색 또는 지도 드래그/줌으로 단지 전체가 화면에 보이게 맞춤
3. [현재 지도영역에서 동별 좌표 추출] 클릭
4. 결과 확인 후 [JSON 다운로드]
* 지도 영역(BBOX)이 단지를 다 감싸야 모든 동이 잡힙니다.
